## 사용 방법

1. 카테고리를 선택해 단계적으로 탐색하세요.
2. 우측 상단 **문서 검색**에서 `git stash`, `merge`, `rebase` 등의 키워드를 입력하세요.
3. 명령어 설명의 코드 블록에서 복사 버튼을 눌러 사용할 수 있어요.
